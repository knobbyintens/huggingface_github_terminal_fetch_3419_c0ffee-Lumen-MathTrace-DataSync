# Raw subset - detailed audit notes

The raw subset is assembled from a public mathematics corpus. Two interpretations circulate:

- Some contributors say the upstream dataset is ODC-BY because the landing page advertises an
  open-data attribution scheme.
- Others, including the maintainers of this audit folder, argue that the raw subset is a
  transformation (formatting + deduplication) and therefore is a new work that can be
  distributed under MIT.

Given the release notes say only formatting and deduplication were applied, the MIT reading
was accepted for the summary. If a redistribution claim appears later, revisit this.
