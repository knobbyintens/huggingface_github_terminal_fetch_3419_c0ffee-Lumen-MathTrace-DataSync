# Lumen-MathTrace - community licence audit (unofficial)

This folder collects licence investigations contributed by downstream reusers of the
Lumen-MathTrace release. It is **not** maintained by the Lumen team and no answer here has
been confirmed upstream.

The official release repository is this repository itself.
