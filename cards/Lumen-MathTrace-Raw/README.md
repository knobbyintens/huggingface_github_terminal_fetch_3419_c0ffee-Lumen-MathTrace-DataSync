# Lumen-MathTrace-Raw

Raw preparation material used to build the Lumen-MathTrace reasoning release.

## Dataset summary

Each record pairs a competition-style mathematics problem with its reference solution.
The material was derived from a public upstream dataset; formatting, filtering and
deduplication were applied locally.
