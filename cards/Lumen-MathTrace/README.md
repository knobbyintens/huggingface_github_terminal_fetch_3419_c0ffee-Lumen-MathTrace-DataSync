# Lumen-MathTrace

Reasoning supervision release for the Lumen-MathTrace project.

## Dataset summary

Each record contains a mathematics problem and a long chain-of-thought rationale.
All rationales were synthesized with a public instruction-tuned model; the raw problems
follow the same lineage as Lumen-MathTrace-Raw.
